# story-reel-remotion

Vídeos verticais programáticos com Remotion (React + TypeScript).

Vídeos verticais para redes sociais feitos em código com Remotion: cada cena é um componente React, e o render é reproduzível.

## Stack
Remotion, React, TypeScript e Tailwind.

## Rodar
```bash
npm install
npx remotion studio     # preview
npx remotion render     # MP4
```
